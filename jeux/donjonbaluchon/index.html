Comment jouer

Le Chevalier

Vous incarnez un preux chevalier. Déplacez-le avec les flèches du clavier ou ZQSD. Sur mobile, utilisez le pad tactile. Sa quête ? Ranger les baluchons de son butin !

Les Baluchons

Vos précieux baluchons doivent être placés sur les emplplacements sacrés (le parquet). Une fois bien placé, le baluchon est sécurisé.

Pousser un baluchon

Marchez vers un baluchon pour le pousser. Vous ne pouvez en pousser qu'un seul à la fois, et seulement si l'espace derrière lui est libre.

Les murs du donjon

Impossible de tirer les baluchons vers vous. Réfléchissez bien avant de pousser ! Si vous coincez un baluchon contre un mur, utilisez le bouton Annuler (touche U).

Condition de victoire

Placez tous les baluchons sur les emplacements sacrés pour terminer le niveau. Moins vous utilisez de pas, plus vous gagnez d'étoiles (jusqu'à 3) !
